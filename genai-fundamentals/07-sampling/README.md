# 07 — Sampling & Decoding

Purpose
Teach decoding strategies and how sampling settings affect creativity, determinism, and safety.

Learning objectives
- Compare greedy, beam, top-k, top-p, and temperature sampling.
- Tune sampling parameters for different application goals.
- Detect and reduce unsafe or toxic outputs via decoding choices and filters.

Key concepts
- Diversity vs fidelity trade-offs, repetition penalties, length penalties.

Exercises
- Generate multiple outputs with varying parameters and analyze differences.
- Implement a simple reranker to choose the best candidate output.

Starter code pointers
- Example scripts that sweep temperature/top-p/top-k values and log outputs.

References
- Decoding algorithm tutorials and model provider safety guidelines.
