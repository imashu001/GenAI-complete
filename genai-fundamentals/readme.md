 
# GenAI Fundamentals — Course Folder

This folder contains structured course material for teaching software developers the foundations of Generative AI. Each subfolder is a self-contained unit with theory, practical exercises, starter code, and references.

Course structure
- `01-llm-fundamentals/` — Core model concepts and family overview
- `02-tokens/` — Tokenization, token-aware prompt engineering, cost considerations
- `03-embeddings/` — Building and using embeddings for retrieval and clustering
- `04-transformers/` — Model internals, architectures, and differences
- `05-attention/` — Self-attention mechanics and implications
- `06-context-windows/` — Long-context strategies, chunking, and sliding windows
- `07-sampling/` — Decoding algorithms and output control
- `08-model-apis/` — Practical API usage, streaming, function-calling, and error handling
