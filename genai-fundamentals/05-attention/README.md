# 05 — Attention

Purpose
Deepen intuition for attention mechanisms and why they enable contextual understanding.

Learning objectives
- Explain dot-product attention and why scaling is needed.
- Visualize attention maps and interpret model focus.
- Understand limitations: quadratic cost and sparsity techniques.

Key concepts
- Scaled dot-product attention, attention scores, softmax, masking.
- Attention visualization methods and insights.

Exercises
- Generate attention maps for short inputs using an available visualizer.
- Experiment with attention masking and observe changes in output.

Starter code pointers
- Use transformer model debug tools or small notebooks that expose attention weights.

References
- Attention tutorials and visualization repos (e.g., BertViz).
