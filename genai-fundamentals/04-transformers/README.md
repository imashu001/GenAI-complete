# 04 — Transformers

Purpose
Explain the transformer architecture and its components at a level suitable for software developers.

Learning objectives
- Describe multi-head attention, positional encodings, and layer stacking.
- Distinguish encoder, decoder, and encoder-decoder architectures.
- Relate architecture choices to common NLP tasks.

Key concepts
- Multi-head self-attention, feed-forward layers, residual connections, layer norm.
- Encoder-only vs decoder-only trade-offs.

Exercises
- Read the transformer diagram and map components to code in a small PyTorch example.
- Modify a tiny transformer config and observe behavior on toy data.

Starter code pointers
- Minimal transformer implementations (e.g., Karpathy microGPT or Hugging Face examples).

References
- "Attention Is All You Need", transformer tutorial notebooks.
