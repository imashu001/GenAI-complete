# 08 — Model APIs & Integration

Purpose
Practical guide for integrating models into applications, handling streaming, function-calling, errors, and cost control.

Learning objectives
- Use SDKs to call models, handle rate limits and retries.
- Implement streaming responses and function-calling patterns.
- Apply input/output validation and basic safety filters.

Key concepts
- Request/response patterns, batching, retries, and exponential backoff.
- Streaming vs non-streaming clients, function-calling and tool interfaces.
- Cost-awareness: token accounting and model selection.

Exercises
- Build a small CLI tool that calls a model and streams the response.
- Add function-calling to the demo for structured outputs (e.g., JSON).

Starter code pointers
- Example client snippets, retry/backoff helper, token accounting utilities.

References
- SDK docs for major providers and example integrations.
