# 01 — LLM Fundamentals

Purpose
Introduce model families, training paradigms, and practical capabilities/limitations of modern LLMs.

Learning objectives
- Differentiate decoder-only vs encoder-decoder models.
- Explain pretraining, fine-tuning, and instruction-tuning.
- Understand strengths/weaknesses: reasoning, memorization, and hallucination.

Key concepts
- Model families (GPT, BERT, LLaMA, PaLM family) and typical use-cases.
- Training signals: next-token prediction, masked language modeling, RLHF.
- Benchmarks and evaluation: perplexity, accuracy, human eval.

Exercises
- Read short summaries of GPT and BERT papers and list differences.
- Compare outputs from two small models on the same prompt and document behavior.

Starter code pointers
- Use a simple SDK (OpenAI/Hugging Face) to call models and compare responses.

References
- "Attention Is All You Need" (background), GPT/BERT original papers.
