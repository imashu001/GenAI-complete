# 06 — Context Windows

Purpose
Cover practical strategies for working within token limits and handling long inputs.

Learning objectives
- Understand context window limits and their implications.
- Implement chunking and sliding-window techniques.
- Use retrieval + summarization to extend effective context.

Key concepts
- Sliding windows, chunk overlap strategies, semantic chunking.
- Summarization-first approach for long documents.

Exercises
- Implement a chunking script and reassemble coherent summaries from chunks.
- Compare simple concatenation vs retrieval-augmented context for an LLM prompt.

Starter code pointers
- Utilities for chunking text, example scripts for overlap and summarization.

References
- Provider docs on long context models and chunking best practices.
