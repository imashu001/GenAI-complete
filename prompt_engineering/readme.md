# Prompt Engineering — Course Folder

This folder contains structured course material for teaching software developers how to use **prompt engineering effectively with Generative AI models**.

Each subfolder is a self-contained unit containing relevant theory, practical examples, exercises, and references.

## Course Structure

* `01-Zero-shot/` — Zero-shot prompting and how to give models clear instructions without examples
* `02-Few-shot/` — Few-shot prompting and using examples to guide model behavior
* `03-Chain-of-thought concepts/` — Understanding reasoning prompts, step-by-step problem solving, and when to use reasoning-oriented techniques
* `04-Structured Outputs/` — Getting predictable, structured responses such as JSON and schema-based outputs
* `05-Function Calling/` — Using prompts and model capabilities to invoke tools and external functions
* `06-Prompt Templates/` — Creating reusable prompts, variables, templates, and patterns for application development
* `07-Prompt Evaluation/` — Evaluating prompt quality, measuring outputs, and improving prompts systematically

## Learning Goals

By the end of this course, you should be able to:

* Understand the fundamentals of prompt engineering
* Write clear and effective prompts
* Use zero-shot and few-shot prompting
* Design prompts for different application scenarios
* Work with structured model outputs
* Use function/tool calling in GenAI applications
* Build reusable prompt templates
* Evaluate and iteratively improve prompts

## Next Steps

Start with `01-Zero-shot/` and work through the modules in order.

Each subfolder contains its own README along with exercises, examples, and supporting resources.
